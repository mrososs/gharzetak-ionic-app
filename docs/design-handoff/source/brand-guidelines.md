# Gharzetak (غرزتك) — Brand guidelines

> "غرزتك... من أول غرزة لآخر لمسة" — *Your stitch, from the first stitch to the final touch.*
> **Working name only — not a registered trademark.** Run a trademark, domain and app-store search before launch.

## Identity
- Name: **غرزتك / Gharzetak**. Alternatives explored: كروشيهك (Crochetak), خيطونة (Khaytoona), غرزتي (Gharzety). Default: غرزتك.
- Logo: original flat 2D mark (pink yarn ball, peach hook, mint thread, stitch lines) on a Primary Purple tile. No 3D, no mascot.
- Minimum mark size 24 px; clear space = hook head diameter.

Extended ramps, ink colours and semantic tokens: `design-tokens.json`. Never put white text on Joyful Pink (2.7:1); use Dark Plum (5.2:1) or Pink Ink #A81F5E on pink tints.

## Typography
Primary: **Playpen Sans Arabic** (Arabic + all UI). Latin text in the English UI: **Playpen Sans**. Fallbacks: Noto Sans Arabic, Segoe UI, Tahoma, system-ui.
Weights: headings 700 · section titles 600–700 · card titles 600 · body 400–500 · buttons 600–700 · tracker numerals 800 tabular · captions 400–500. Arabic line-height ≥ 1.45, body 1.7; no letter-spacing on Arabic.

## Imagery
Real, warm, handmade photography; natural light; no 3D renders; no AI mascot. Radius 28 (hero), 16–20 (cards). Until photos exist, labelled tonal placeholders are used — see `asset-manifest.json`.

## Voice
Warm, encouraging, precise about craft terms (always show abbreviations), honest about demo features.

## Accessibility
Text ≥ 4.5:1, UI ≥ 3:1, targets ≥ 44 px, visible 3 px Primary focus ring, direction-aware icons, reduced-motion respected.
